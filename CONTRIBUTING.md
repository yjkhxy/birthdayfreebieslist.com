# Contributing to Birthday Freebies List

Help readers make better birthday plans by correcting reward conditions and linking to evidence.

## Report a reward correction

Use the [reward correction form](https://github.com/yjkhxy/birthdayfreebieslist.com/issues/new?template=reward-correction.yml) and include:

- The brand and affected directory page.
- What is incorrect, missing or outdated.
- An official rewards page, terms page or FAQ supporting the change. If none is available, say that the claim remains unverified.
- The date you checked the source and the country or redemption channel involved.
- Relevant enrollment deadlines, prior spending, minimum purchase, membership tier, expiration or location restrictions.

A single store visit or account offer can identify a useful lead, but does not establish a program-wide benefit. Distinguish a free item from a discount, points promotion, paid offer or unverified claim.

Do not include your full birthday, address, login details, account identifiers, reward codes, or personal information from receipts and screenshots. Public issues can be read by anyone. Use the website's [contact page](https://birthdayfreebieslist.com/contact) for a question unsuitable for a public issue; never send passwords or reward codes.

## Improve this documentation

Pull requests can fix explanations, broken links and planning guidance. Keep changes focused, use descriptive link text, and cite official evidence for factual reward changes. Avoid unsupported savings totals or claims that every listed program is free.

This repository contains public documentation. A merged change here does not automatically update the website's separate source or data. Website corrections need a separate review and update.

## Suggest a resource

Only suggest resources that directly help readers compare or claim birthday rewards. Explain their value and disclose any affiliation. Unrelated promotional links, link exchanges and bulk submissions do not belong in this guide.
